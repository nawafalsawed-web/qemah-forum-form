# نموذج تسجيل زوار جناح قمة للمزادات · منتدى الصناعة السعودية 2026

**الرابط:** https://nawafalsawed-web.github.io/qemah-forum-form/

## للمنظّمين
1. افتح الرابط على الجوال واكتب اسمك مرة واحدة في خانة «المنظّم» (يُحفظ على الجهاز).
2. سجّل الزائر: الاسم والجوال والفئة إلزامية، والباقي حسب المتاح.
3. لو انقطع النت يُحفظ التسجيل على الجهاز ويُرسل تلقائياً عند الرجوع (شارة «بانتظار الإرسال»).
4. النسخة الورقية الاحتياطية: `نموذج-ورقي.pdf`، والـQR للرابط: `qr-form.png`.

## التقرير بعد المعرض
```
python3 report.py
```
يسحب كل التسجيلات ويكتب `تقرير-زوار-الجناح.xlsx` (ورقة التفاصيل + ورقة الملخص) ويطبع الملخص. يعمل على جهاز نواف فقط (يستخدم تسجيل دخول Firebase CLI).

## ملاحظة تقنية
البيانات في Firestore مشروع `ahdaf-influencers` كوليكشن `qemah_visitors`، قواعد الإنشاء فقط (لا قراءة من الفورم). قواعد `fada_leads` أُعيدت في نفس النشر.
